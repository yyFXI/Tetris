# Tetris

A simple Tetris game implemented in Python using Pygame.

## Requirements

- Python 3.x
- Pygame

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yyFXI/Tetris.git
   cd Tetris
   ```

2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Game

```bash
python tetris.py
```
